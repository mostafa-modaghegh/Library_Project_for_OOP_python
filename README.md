# Library Management System

This is a simple Library Management System project developed using Python and Object-Oriented Programming (OOP).

## Features

- Admin and student sections
- User login
- Book management
- Basic library operations

## Technologies

- Python
- Object-Oriented Programming (OOP)

## Project Files

- `index.py` – Main program
- `login.py` – Login functionality
- `admin.py` – Admin operations
- `student.py` – Student operations
- `book.py` – Book management

## Purpose

This project was developed for learning and practicing Python and OOP concepts.
